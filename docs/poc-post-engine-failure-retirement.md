# POC cleanup after a failed Podman workload

The protected Root publisher binds each G06 cell to its exact native configuration and cleanup policy. All G06 business and operating cases can release owned resources as soon as Root verifies the original terminal failure, secures the private evidence and proves access withdrawal and a stopped VM where one exists. A lease issued under an earlier policy requires an exact, reviewed authorization bound to its original policy, lease and resources.

Root binds the native terminal result to the original execution and verifies the locally recorded process outcome. Root saves the original lease, terminal result, and both complete capture streams in an atomic private archive. Before removing resources, Root verifies the drained worker, withdrawn network and certificate access, exact project and resource ownership, and any stopped VM's original UUID. An exact private copy of the configured VM image is eligible for removal with the lease resources. Root reads the separately held default image before and after cleanup.

The lease stays open during cleanup. Root records the exact effects and runs a separate readback of the archive, journal, and live resources before closing the lease. A missing, mismatched, or unresolved effect keeps the runner held. Completed effects can be reconciled after interruption. The original GitHub job retains its failure conclusion.
